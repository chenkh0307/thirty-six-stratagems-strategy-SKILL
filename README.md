# 三十六計執行策略 Skill

將《三十六計》轉化為可供 AI 使用的局勢診斷與執行策略框架。

本 Skill 不只是替問題套上計策名稱，而是先分析目標、利害關係人、資源、時機、資訊差與退路，再從三十六計中選出適合的主計、輔計及退場計，最後形成可執行、可驗證、可停止的行動方案。

## 適用情境

- 商業競爭、產品定位與市場進入策略。
- 談判、合作、採購及利害關係人管理。
- 組織權責、內部競合與資源配置。
- 專案卡關、危機處理、止損與退出決策。
- 法律專案的程序規劃、證據保全與風險分析。
- 需要預測對手反應、設計反制或進行情境推演時。

本 Skill 不適合單純的事實查詢，也不應被用來合理化欺詐、傷害、報復、偽造證據、妨害司法或未經授權的外部行動。

## 核心特色

1. **先判斷局勢，再選計策**：依優勢、均勢、主動破局、混亂、內部競合及劣勢等態勢，縮小候選範圍。
2. **比較多個候選策略**：每一計都要檢查成立條件、預期效果、風險與失效訊號。
3. **形成策略組合**：指定主計、輔計與退場計，避免任意堆砌計策名稱。
4. **落實為執行方案**：輸出責任角色、資源、時程、檢核證據、停止條件與備用方案。
5. **加入反制推演**：站在對手角度檢查計畫弱點、可能反應及單點失敗。
6. **設置風險閘門**：高風險計策預設用於辨識、防禦與合規紅隊分析。

## 安裝方法

### 方法一：複製到 Codex Skills 目錄

在 PowerShell 執行：

```powershell
git clone https://github.com/chenkh0307/thirty-six-stratagems-strategy-SKILL.git "$env:USERPROFILE\.codex\skills\thirty-six-stratagems-strategy"
```

如果目的資料夾已存在，請先確認其中是否有需要保留的修改，再決定更新或另行備份；不要直接覆蓋未提交的內容。

### 方法二：在專案中使用

將整個儲存庫放入可供 AI 讀取的專案目錄，並明確指定 `SKILL.md` 的位置。若平台支援技能探索，可把資料夾加入該平台指定的 Skills 目錄。

## 基本使用方法

在提示詞中直接呼叫：

```text
使用 $thirty-six-stratagems-strategy 分析目前局勢，提出具體執行方案、風險防線與退場條件。
```

為了得到更精準的結果，建議一併提供：

- 想達成的具體目標。
- 必須完成的期限。
- 已知的利害關係人及其立場。
- 我方與對方掌握的資源。
- 不可違反的法律、預算、倫理或關係底線。
- 已嘗試的方法及其結果。
- 可接受與不可接受的風險。

## 提示詞範例

### 商業競爭

```text
使用 $thirty-six-stratagems-strategy 分析以下市場競爭局勢。

目標：六個月內讓新產品取得第一批企業客戶。
限制：預算新臺幣 100 萬元，不採用價格戰，也不得貶低競爭者。
現況：競爭者品牌較強，但導入速度慢；我方產品規模較小，但客製化速度快。

請比較 3 個候選計策，選出主計、輔計與退場計，並提供 30 天執行表、成功指標、停止條件及對手可能的反制。
```

### 談判策略

```text
使用 $thirty-six-stratagems-strategy 規劃供應商續約談判。

我方目標是降低總成本 8%，但不能犧牲交付穩定性。供應商知道我方短期內不容易更換，也可能要求延長合約期限。

請區分已知事實、推論與未知事項，提出談判前準備、會議中的行動順序、可交換條件、對方可能反制及談判破裂時的 Plan B。
```

### 危機與止損

```text
使用 $thirty-six-stratagems-strategy 判斷這個專案應該繼續、縮減或退出。

請特別比較「以逸待勞」「李代桃僵」與「走為上」，列出各自的成立條件、成本、失效訊號，以及未來兩週可以驗證的最小行動。
```

### 法律專案

```text
使用 $thirty-six-stratagems-strategy 規劃爭議案件的證據保全與協商順序。

不得提出欺騙、偽造、非法取證或影響證人的方法。請先列出證據缺口、時效、保密義務與利益衝突，再提出主計、輔計、退場計及每一步所需授權。
```

## 建議輸出格式

一次完整分析通常包含：

1. 決策摘要與成功指標。
2. 已知事實、推論及未知事項。
3. 當前局勢屬於哪一類態勢。
4. 2–4 個候選計策的比較。
5. 主計、輔計與退場計。
6. 分階段執行表。
7. 風險、對手反制與防線。
8. 停止條件、轉向條件及立即可做的下一步。

詳細欄位請參考 [`references/execution-template.md`](references/execution-template.md)。

## 使用原則與風險邊界

- 三十六計是思考框架，不是事實證據，也不是成功保證。
- 歷史典故只能用來提示可能機制，不能取代現代資料與驗證。
- 優先採用合法、可逆、低成本、可試驗的行動。
- 「借刀殺人」「美人計」「反間計」「苦肉計」等高風險計策，預設用於風險辨識、防禦及合規分析。
- 不得把 Skill 的分析視為對發布、付款、簽約、刪除資料或聯絡第三方的授權。
- 法律、醫療、金融及其他高風險事項，仍應由具資格的專業人士依具體事實覆核。
